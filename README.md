# Kern & Kante

Fictional commercial woodworking website built as a portfolio/demo project.

## Start

```bash
npm install
npm run dev
```

## Structure

- `src/components` — reusable UI components
- `src/sections` — page-level sections
- `src/data` — project/content data
- `src/styles` — design tokens and global styles

The image files in `public/images` are placeholders. Replace them with properly licensed photos (for example from Pexels) while keeping the same filenames or update the paths in `src/data/projects.ts`.
